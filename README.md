# Rentals For Students
Platform to find rentals for students

## Technologies
- Python
- Flask
- SQLite

## Instalation
- Clone the repository
- Install flask
- Create the database
- Run the server

## Commands
``` 
git clone https://github.com/Gael-Valerio/rentas-estudiantes.git
pip install flask
python database.py
python app.py
```
