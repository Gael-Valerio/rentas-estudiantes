# Renta Para Estudiantes
Plataforma para encontrar rentas para estudiantes

## Tecnologías
- Python
- Flask
- SQLite

## Instalacion
- Clonar el respositorio
- Instalar Flask
- Crear la base de datos
- Correr el servidor

## Comandos
``` 
git clone https://github.com/Gael-Valerio/rentas-estudiantes.git
pip install flask
python database.py
python app.py
```
